# 18 · 3D 场景坐标系（已按讨论定稿）

> 右手系，Z 向上；主板面 = Y-Z 平面，X 是法线。
> 主板厚度放 X 负方向（-6..0）；I/O 垂直主板；机箱透明、上沿与主板上沿对齐。

## 18.1 轴

| 轴 | 0 点 | 正方向 | 对应 |
|---|---|---|---|
| X | 主板正面 | 法线，指向机箱内 | 显卡宽度 |
| Y | 后置 I/O 面 | 向前（深度） | 显卡长度 |
| Z | 主板下沿 | 向上 | PCIe 槽位 |

右手性：`X × Y = Z`。

## 18.2 常量

| 常量 | 值 |
|---|---|
| 板厚 | 6（X -6..0） |
| I/O | X 0..45，Y 0..6，Z 板上沿往下 160 |
| PCIe 槽距 | 20.32 |
| **第一个槽** | **I/O 下缘 − 6.35**（0.25"） |
| 显卡宽（X） | 110 |
| 机箱上沿 | = 主板上沿 |

## 18.3 槽位

```text
firstSlotZ = (boardHeight - 160) - 6.35
slot(k)    = firstSlotZ - (k-1) × 20.32   // k=1 最上
```

| 板型 | 高 | 槽数 | 第一个槽 | 最后一个槽 |
|---|---:|---:|---:|---:|
| ATX | 305 | 7 | 138.65 | 16.73 |
| mATX | 244 | 4 | 77.65 | 16.69 |
| Mini-ITX | 170 | 1 | **3.65** | 3.65 |

- Mini-ITX 单槽贴近板底；3 槽卡向下会到 **Z 负数**，允许，不 clamp；
- 显卡挡板上沿 = 槽位中线，卡身**向下**占 thickness（2–3 槽）。

## 18.4 起止坐标（ATX，337mm 卡，第 2 槽）

| 对象 | X | Y | Z |
|---|---|---|---|
| 主板 | -6 → 0 | 0 → 244 | 0 → 305 |
| 后置 I/O | 0 → 45 | 0 → 6 | 145 → 305 |
| 第 1 槽中线 | — | — | 138.65 |
| 第 2 槽中线 | — | — | 118.33 |
| 337mm 显卡（3 槽） | 0 → 110 | 0 → 337 | 57.33 → 118.33 |
| 机箱限长面 | 0 → 110 | 320 | 57.33 → 118.33 |
| 160mm 散热 | 0 → 160 | 50 → 180 | 165 → 295 |
| 侧板限高面 | 160 | 50 → 180 | 165 → 295 |
| 机箱允许空间 | -10 → 180 | -20 → 390 | 0 → 305（上沿对齐） |

验证：GPU 顶 118.33 < I/O 下沿 145 → **不再冲突**。

## 18.5 ITX 单槽

```text
boardHeight = 170
firstSlotZ  = 170 - 160 - 6.35 = 3.65
GPU 3 槽：3.65 - 61 = -57.35 → 3.65
```

允许 Z 为负；机箱/主板仍按上沿对齐，不 clamp 显卡。

## 18.6 渲染约定

- 纹理面内双线性映射，线条随面透视；不做风扇贴图；
- 机箱半透明 ghost，可隐藏；
- 限制面半透明 + 虚线，超出变红；
- 机箱上沿 = 主板上沿。
