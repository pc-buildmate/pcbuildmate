# 18 · 3D 场景坐标系（已按讨论定稿）

> 右手系，Z 向上；主板面 = Y-Z 平面，X 是法线。
> 主板厚度放 X 负方向（-6..0），零件从 X=0 向外长；机箱上沿与主板上沿对齐。

## 18.1 轴

| 轴 | 0 点 | 正方向 | 对应 |
|---|---|---|---|
| X | 主板正面 | 法线，指向机箱内 | 显卡宽度 |
| Y | 后置 I/O 面 | 向前（深度） | 显卡长度 |
| Z | 主板下沿 | 向上 | PCIe 槽位排列 |

右手性：`X × Y = Z`。

## 18.2 常量

| 常量 | 值 |
|---|---|
| 板厚 | 6（X -6..0） |
| PCIe 槽距 | 20.32 |
| 最后一槽中线 | **147** |
| 槽位网格 | 7 格，`slot(k) = 147 + (7-k)×20.32` |
| I/O | X 0..45，Y 0..6，Z 板上沿往下 160 |
| 显卡宽（X） | 110 |
| 机箱上沿 | = 主板上沿 |

## 18.3 板型

| 板型 | 高 Z | 深 Y | 槽数 | 取的槽 |
|---|---:|---:|---:|---|
| ATX | 305 | 244 | 7 | 268.92 → 147.00 |
| mATX | 244 | 244 | 4 | 207.96 → 147.00 |
| ITX | 170 | 170 | 1 | **268.92**（高出板顶 98.92，允许 Z 为负/出板，不 clamp） |

## 18.5 规则

- 机箱默认透明（ghost），可隐藏；
- 限制面半透明 + 虚线，超出变红；
- ITX 单槽在顶部网格位置，显卡可以高出板顶，不 clamp；
- 纹理用面内双线性映射，不做风扇贴图；
- 机箱上沿 = 主板上沿，I/O 左上角与板上沿对齐。
