# 18 · 3D 场景坐标系（v1，部分参数待细化）

> 状态：**已实现 v1**，但 §18.8 列出的参数仍有估算/待确认项。
> 本文先把坐标写死，再画图；改参数只改 `Scene3d.kt` 的常量，不要重写渲染器。
>
> 右手系，Z 向上；主板面 = Y-Z 平面，X 是法线。
> 主板厚度放 X 负方向（-6..0）；I/O 垂直主板；机箱透明、上沿与主板上沿对齐。

## 18.1 轴

| 轴 | 0 点 | 正方向 | 对应 |
|---|---|---|---|
| X | 主板正面 | 法线，指向机箱内 | 显卡宽度 |
| Y | 后置 I/O 面 | 向前（深度） | 显卡长度 |
| Z | 主板下沿 | 向上 | PCIe 槽位 |

右手性：`X × Y = Z`。

## 18.2 常量（当前实现）

| 常量 | 值 | 说明 |
|---|---|---|
| 板厚 | 6（X -6..0） | 板体在负 X，零件从 0 往外长 |
| I/O | X 0..45，Y 0..6，Z 板上沿往下 160 | 见 §18.8 待确认 |
| PCIe 槽距 | 20.32 | 0.8" |
| 第一个槽（全板型） | I/O 下缘 − **7.52** | 0.30 in = [7.52] mm（图纸） |
| 显卡宽（X） | 110 | 口述值；ATX 常见 120 |
| 机箱上沿 | = 主板上沿 | 不写死 305/345 |
| 散热离板间隙 | 1 mm | 避免与板面共面穿模 |

## 18.3 槽位公式

```text
// 首个 x16 槽：目录字段优先（ADR-0011），缺失回退常量
firstSlotZ = 主板 pcieX16SlotMm ?: ((boardHeight - 160) - 7.52)   // 0.30 in
slot(k)    = firstSlotZ - (k-1) × 20.32   // k=1 最上
slotCount  = 主板 pcieSlotCount ?: 按板型推断
```

| 板型 | 高 | 槽数（回退） | 首个 x16 槽（字段 / 回退） | 显卡挡板上沿 |
|---|---:|---:|---:|---:|
| ATX | 305 | 7 | 137.5 / 137.48 | 137.5（字段） |
| mATX | 244 | 4 | 76.5 / 76.48 | 76.5（字段） |
| Mini-ITX | 170 | 1 | 无字段 → **2.48** | 2.48 |

- 显卡挡板上沿 = 首个 x16 槽中线，卡身**向下**占 thickness（2–3 槽）；
- 显卡不再固定第 2 槽：`pcieX16SlotMm` 就是它所在槽；缺字段才回退 I/O 下缘 − 7.52；
- Mini-ITX 单槽 = 170 − 160 − 7.52 = **2.48**；3 槽卡到 **Z = 2.48 − 61 = −58.52**，允许负数，不 clamp。

## 18.4 起止坐标（ATX，337mm 卡，首个 x16 槽）

| 对象 | X | Y | Z |
|---|---|---|---|
| 主板 | -6 → 0 | 0 → 244 | 0 → 305 |
| 后置 I/O | 0 → 45 | 0 → 6 | 145 → 305 |
| 首个 x16 槽中线（字段 137.5 / 回退 137.48） | — | — | 137.5 |
| 337mm 显卡（3 槽） | 0 → 110 | 0 → 337 | 76.5 → 137.5 |
| 机箱限长面 | 0 → 110 | 320 | 76.5 → 137.5 |
| 160mm 散热 | 1 → 161 | 50 → 180 | 165 → 295 |
| 侧板限高面 | 160 | 50 → 180 | 165 → 295 |
| 机箱允许空间 | -10 → 180 | -20 → 390 | 0 → 305（上沿对齐） |

校验：GPU 顶 `137.5` < I/O 下沿 `145` → 不相交，间隙 7.5 ≈ 0.30 in。

## 18.5 ITX 单槽（与 ATX 同一规则）

```text
boardHeight = 170
I/O 下缘    = 170 - 160 = 10
firstSlotZ  = 10 - 7.52 = 2.48
GPU 3 槽：2.48 - 61 = -58.52 → 2.48
```

不再为 ITX 单独分支；允许 Z 为负，不 clamp 显卡。

## 18.6 渲染约定

- 纹理用面内双线性 `(u,v)` 映射，线条随面透视变化，不锁屏幕角度；
- **不做风扇贴图**（数量/角度因卡而异，容易画错）；
- 机箱半透明 ghost，可隐藏；限制面半透明 + 虚线，超出变红；
- 盒体是尺寸示意，不是外观模型。
