# 18 · 3D 场景坐标系（v1，部分参数待细化）

> 状态：**已实现 v1**，但 §18.8 列出的参数仍有估算/待确认项。
> 本文先把坐标写死，再画图；改参数只改 `Scene3d.kt` 的常量，不要重写渲染器。
>
> 右手系，Z 向上；主板面 = Y-Z 平面，X 是法线。
> 主板厚度放 X 负方向（-6..0）；I/O 垂直主板；机箱透明、上沿与主板上沿对齐。

## 18.1 轴

| 轴 | 0 点 | 正方向 | 对应 |
|---|---|---|---|
| X | 主板正面 | 法线，指向机箱内 | 显卡宽度 |
| Y | 后置 I/O 面 | 向前（深度） | 显卡长度 |
| Z | 主板下沿 | 向上 | PCIe 槽位 |

右手性：`X × Y = Z`。

## 18.2 常量（当前实现）

| 常量 | 值 | 说明 |
|---|---|---|
| 板厚 | 6（X -6..0） | 板体在负 X，零件从 0 往外长 |
| I/O | X 0..45，Y 0..6，Z 板上沿往下 160 | 见 §18.8 待确认 |
| PCIe 槽距 | 20.32 | 0.8" |
| 第一个槽（ATX/mATX） | I/O 下缘 − 6.35 | 0.25" |
| Mini-ITX 单槽 | **板下缘 + 6.35** | 0.25" 英制，从下缘往上 |
| 显卡宽（X） | 110 | 口述值；ATX 常见 120 |
| 机箱上沿 | = 主板上沿 | 不写死 305/345 |
| 散热离板间隙 | 1 mm | 避免与板面共面穿模 |

## 18.3 槽位公式

```text
// ATX / mATX
firstSlotZ = (boardHeight - 160) - 6.35

// Mini-ITX（只有 1 个槽）
firstSlotZ = 6.35          // 从板下缘往上 0.25"，不是从 I/O 算

slot(k) = firstSlotZ - (k-1) × 20.32   // k=1 最上
```

| 板型 | 高 | 槽数 | 第一个槽 | 最后一个槽 |
|---|---:|---:|---:|---:|
| ATX | 305 | 7 | 138.65 | 16.73 |
| mATX | 244 | 4 | 77.65 | 16.69 |
| Mini-ITX | 170 | 1 | **6.35** | 6.35 |

- 显卡挡板上沿 = 槽位中线，卡身**向下**占 thickness（2–3 槽）；
- Mini-ITX 单槽 = 下缘 + 6.35；3 槽卡到 **Z = 6.35 − 61 = −54.65**，允许负数，不 clamp；
- ITX 的 I/O 下缘 = 170 − 160 = 10 > 6.35，所以槽位在 I/O **下方**，不相交。

## 18.4 起止坐标（ATX，337mm 卡，第 2 槽）

| 对象 | X | Y | Z |
|---|---|---|---|
| 主板 | -6 → 0 | 0 → 244 | 0 → 305 |
| 后置 I/O | 0 → 45 | 0 → 6 | 145 → 305 |
| 第 1 槽中线 | — | — | 138.65 |
| 第 2 槽中线 | — | — | 118.33 |
| 337mm 显卡（3 槽） | 0 → 110 | 0 → 337 | 57.33 → 118.33 |
| 机箱限长面 | 0 → 110 | 320 | 57.33 → 118.33 |
| 160mm 散热 | 1 → 161 | 50 → 180 | 165 → 295 |
| 侧板限高面 | 160 | 50 → 180 | 165 → 295 |
| 机箱允许空间 | -10 → 180 | -20 → 390 | 0 → 305（上沿对齐） |

校验：GPU 顶 `118.33` < I/O 下沿 `145` → 不相交。

## 18.5 ITX 单槽（英制 0.25" 从下缘量）

```text
boardHeight = 170
firstSlotZ  = 0.25" = 6.35        // 从板下缘往上，不是从 I/O 下缘
I/O 下缘    = 170 - 160 = 10      // 10 > 6.35，槽位在 I/O 下方
GPU 3 槽：6.35 - 61 = -54.65 → 6.35
```

允许 Z 为负；机箱/主板仍按上沿对齐，不 clamp 显卡。

## 18.6 渲染约定

- 纹理用面内双线性 `(u,v)` 映射，线条随面透视变化，不锁屏幕角度；
- **不做风扇贴图**（数量/角度因卡而异，容易画错）；
- 机箱半透明 ghost，可隐藏；限制面半透明 + 虚线，超出变红；
- 盒体是尺寸示意，不是外观模型。

## 18.7 改参数的入口

| 想改 | 改哪里 |
|---|---|
| I/O 尺寸/方向 | `SceneBuilder.IO_WIDTH_MM / IO_THICKNESS_MM / IO_HEIGHT_MM` |
| 槽距 / 首槽偏移 | `SLOT_PITCH_MM / FIRST_SLOT_FROM_IO_MM` |
| 显卡宽 / 取第几槽 | `GPU_WIDTH_MM / GPU_SLOT_INDEX` |
| 板型尺寸/槽数 | `boardHeight / boardDepth / slotCount` |
| 机箱外廓 | `SceneBuilder` 末尾 case ghost 的 `min/max` |
| 相机 | `ViewPose` 默认 `yaw/pitch/distance/focal` |

## 18.8 待细化 / 待确认（**重要**）

| # | 参数 | 当前值 | 依据 | 风险 / 待确认 |
|---|---|---|---|---|
| 1 | I/O 方向 | 45(X) × 160(Z) | 需求方口述 | ATX 标准是 159 宽 × 44.7 高；若改成 160(X)×45(Z)，GPU 与 I/O 的关系要重算 |
| 2 | 首个槽偏移 | ATX/mATX：I/O 下缘 − 6.35；ITX：下缘 + 6.35 | 0.25" 是**英制**；ITX 特指从下缘往上 | ITX 已按英制 6.35 修正；ATX 的"IO 下缘−6.35"仍待真实板图核对 |
| 3 | 显卡所在槽 | 固定第 2 槽 | 常见第一条 x16 | 部分板第一条 x16 是第 1 槽；应由板型/芯片组决定 |
| 4 | 显卡宽 | 110 | 需求方口述 | ATX 全高挡板常见 120；契约没有该字段 |
| 5 | 散热器位置 | X 1→161、Y 50→180、Z 165→295 | 估算（CPU 插座位置） | 未从主板图读取 CPU socket 坐标；可能需按 board layout 调 |
| 6 | 散热器底面 | 130×130 | 估算 | 双塔/下压式尺寸差异大 |
| 7 | 机箱外廓 | 深=限长+70，高=板高，宽=限高+20 | 估算 | 目录没有机箱外形字段；只用于"允许空间"示意 |
| 8 | 相机默认角度 | yaw=-1.35，pitch=0.35 | 手工调 | 只为默认视角好看，不是规格 |
| 9 | 板型尺寸映射 | ATX 305×244、mATX 244×244、ITX 170×170 | SilverStone/ZOL | EATX 等未验证 |
| 10 | Z 负数策略 | ITX 单槽 6.35，3 槽卡到 -54.65 | 允许 | UI 不 clamp；若要做"越界警告"需另定义 |

> 这些不是 bug，是 v1 的已知近似；答辩时要主动说"盒体尺寸示意，部分参数是估算/待细化"。
