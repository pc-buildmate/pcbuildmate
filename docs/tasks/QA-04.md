- `gen-fixtures.mjs` 只写 `rules-v1.json`、`fixtures-rules-v1.json`、`fixtures-anchor-v1.json`；`--check` 也只比这三个。
- `check-demo-catalogue.mjs`：32 条、8 类每类 ≥3、id 唯一、`isDemo` / `catalogueVersion` / `priceDate` 一致、三态自洽（`EMPTY` 不带 value/numeric；numeric 必须等于 value）、字段路径在 §3.3、锚点 7800→7900；`--self-test` 至少覆盖 7 种改坏。

- 输出确定性：不读时钟、不读网络，重复运行结果一致。
