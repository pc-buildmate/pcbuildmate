## 输出契约

`node tools/gen-matrix.mjs` 写 `build/reports/matrix.json`：

```json
{ "tests": [ { "id": "fx_...", "status": "passed|failed|skipped",
               "tags": ["rule:GPU_CASE_LENGTH", "case:CONFLICT"] } ] }
```

- 规则：60 条 fixture 各自的 `ruleId` + `case`，只有当 `FixtureTest` 的 60 条断言全过时才记 `passed`；
- 状态机：76 格，只有当对应 `full matrix` 测试通过时才记 `passed`；
- 任一测试产物缺失 → 退出码 1，不生成可用于放行的矩阵。

`node tools/check-matrix.mjs`：

- 有 `matrix.json` → 按真实结果算 `rules __/60`、`fsm __/76`；已接入的块出现空格子 → 退出码 1；
- 无 `matrix.json` → 规格模式（打印期望格数，退出码 0）；
- `--strict` → 三块矩阵（含 `inv`）都必须已接入，否则退出码 1；
- `--mutations` 行为不变。
