# D5-01 · 替换建议（先过滤，再排序）

> 状态：**done**（2026-11-04）｜分支：`feat/d5-replacement`｜Owner：Captain/AI

## 1. 目标

实现 `DefaultReplacementAdvisor(catalogue, evaluator)`：给定 base revision 与一条 `RuleOutcome.Conflict`，
返回**先过硬约束、再排序**的候选；无候选时给结构化原因。

**不做**：不改 build；不做推荐；不做比较；不声称最优。

## 2. 允许修改的路径

```
domain/replacement/**
ci/allowlist.txt      # 仅测试依赖 :domain:rules 的说明
```

## 3. 只读输入

- `docs/06-modules.md` D5
- `docs/02-contracts.md` INV-08 / INV-14
- `contracts/.../Suggestions.kt`、`Outcomes.kt`、`Ports.kt`
- `assets/fixtures/fixtures-anchor-v1.json` 的 `fx_suggestion_300_plus_100`

## 4. 输出契约

- `SuggestionResult.baseRevisionId / conflictRuleId / conflictId` 与输入一致；
- 候选必须让目标 `conflictId` 不再是 Conflict；
- 不得引入**新的** BLOCKER Conflict（base 已有的不算新）；
- 其它规则变化记入 `affectsOtherRules`；
- 排序：价格差升序 → `affectsOtherRules.size` 升序 → `componentId` 字典序；
- 无候选：`candidates=[]` + `noCandidate(blockingConstraint="RULE_ID:fieldPath")`。

## 5. 验收命令

```bash
./gradlew :domain:replacement:test
node ci/check-boundaries.mjs
node ci/check-keywords.mjs
```

## 6. 结果

- 5 个测试全绿：锚点 +100/rank1、应用后 7900/BIOS 仍 UNVERIFIED、无候选、新 BLOCKER 过滤、确定性。
- 锚点：`gpu-demo-337` → `gpu-demo-300`，`priceDeltaCny=100`，`rank=1`。
- 边界/关键词检查 0 违规。
- 测试用 `:domain:rules` 的真实引擎；生产依赖仍只有 `:contracts`（allowlist 记录）。

## 7. 已知偏差

- “对剩余余量影响小”用 `affectsOtherRules.size` 作为代理；没有预算/余量字段可算更精确的排序。
- 只替换冲突的 **left** 侧组件（规则 DSL 把被约束量放左边）；如果 UI 需要同时建议换右侧，需要扩展契约。
- `specDelta` 的值格式是 `"old -> new"`，只覆盖发生变化的字段；文案 key 由 UI 决定。
