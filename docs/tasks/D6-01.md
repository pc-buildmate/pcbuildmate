# D6-01 · 构建比较 + 保存快照

> 状态：**done**（2026-11-04）｜分支：`feat/d6-compare`｜Owner：Captain/AI

## 1. 目标

- `DefaultBuildComparator`：2 份已保存配置并排比较，只读 revision + 诊断，不调用规则引擎；
- ViewModel 在诊断完成/应用后保存快照，Workspace 可进入 Compare；
- Compare 页展示总价、兼容状态、分类花费，差异高亮。

## 2. 允许修改的路径

```
domain/compare/**
feature/src/main/kotlin/pcbuildmate/feature/workspace/**
ui/src/main/kotlin/pcbuildmate/ui/**
app/src/main/kotlin/pcbuildmate/app/**
```

## 3. 输出契约

- 字段：`totalCny`、`status`、8 个分类花费；
- `diagnoses[i] != null <=> diagnosis.revisionId == revision.id`，过期 -> null + `COMPARE_DIAGNOSTICS_STALE`；
- `< 2` 份 -> `COMPARE_INSUFFICIENT_BUILDS`，不返回部分比较；
- build 不存在 -> `IllegalArgumentException`，fail-closed；
- 不重新计算规则。

## 4. 验收命令

```bash
./gradlew :domain:compare:test
./gradlew :app:assembleDebug
node ci/check-boundaries.mjs
```

## 5. 结果

- 4 条 comparator 测试：对齐/高亮、过期诊断、少于 2 份、缺失 build；
- 真机：A = 7800（冲突）、B = 7900（未验证），总价/状态/显卡差异高亮；
- 自动保存：诊断完成后存 A，应用后存 B；同一 revision 重复保存只更新诊断。

## 6. 已知偏差

- 功耗余量 / 升级余量 / 物理尺寸未输出：需要目录规格，当前 comparator 不依赖 CataloguePort；
- 目录版本不同没有专门 warning key（暂不输出，避免用错文案）；
- 最多并排 2 份；3 份需要 UI 横向滚动。
