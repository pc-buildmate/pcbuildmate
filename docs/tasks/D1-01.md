# D1-01 · 目录解析与 CataloguePort 实现

> 状态：**done**（2026-11-04）｜分支：`chore/s1-scaffold`｜Owner：Captain/AI

## 1. 目标

把 `assets/catalogue/demo-v1.json` 解析成不可变 `CatalogueRecord` 列表，实现 `CataloguePort`，
并按 `docs/03 §3.3` 冻结表做 seed 校验；失败 fail-fast。

**不做**：兼容性判定、推荐、替换、UI。

## 2. 允许修改的路径

```
data/**
```

## 3. 只读输入

- `docs/06-modules.md` §D1
- `contracts/src/main/kotlin/pcbuildmate/contracts/Model.kt`、`Ports.kt`
- `docs/03-rules.md` §3.3（字段路径、CSV、数值、版本）
- `assets/catalogue/demo-v1.json`
- `contracts-test/.../CataloguePortContract.kt`

## 4. 输出契约

- `CatalogueParser.parse(text): CatalogueSnapshot`
- `AssetCatalogueAdapter(source): CataloguePort`；`assetCatalogue(context)` 为 Android 入口
- 查询按 `componentId` 字典序；`search` 对 model/partNumber 大小写不敏感
- `getById` 未命中返回 `null`
- 重复 id / 未知路径 / CSV token 非法 / 版本非法 / 组件版本与目录不一致 → `IllegalArgumentException`

## 7. 已知偏差

- `fixtures-rules-v1.json` 里的 catalogue 记录不走本解析器（fixture 有自己的结构）；
  规则引擎测试会单独解析 fixture。
- `priceDate <= catalogueVersion 发布日期` 未校验：目录版本没有日期字段，无法判定。
- `numeric` 与 `value` 不一致时目前只在 numeric 非空时检查；`value` 非数值但 numeric 有值的组合会被放过（待补）。
