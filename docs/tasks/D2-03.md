无独显且 CPU 无核显时，拒绝生成/应用/导入该配置。D4 已经在推荐时过滤；
本任务补手动删 GPU、导入 plan card 的入口。

## 规则

```text
gpu != null                          -> OK
gpu == null && cpu.integratedGraphics == YES -> OK
gpu == null && cpu.integratedGraphics != YES -> Rejected(NO_DISPLAY_OUTPUT)
```

## 验收

- `:domain:revision:test` 3 条：有 GPU；无 GPU + 9600X；无 GPU + 7500F；
- `StartCheck` 前调用；`ImportPlanCard` 前调用；
- UI 显示 `TextKey`（可先复用 `diagnostics_failed`，后续补 key）；
