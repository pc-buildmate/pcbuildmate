> 2026-11-15｜APK：`artifacts/PC-Buildmate-1.0.0-defense.apk`
> 目标：15 分钟，其中 8–9 分钟真机演示；数字与 App 一致，不承诺范围外能力。

## 0. 演示前 60 秒

- 装 signed APK，**清除应用数据**（Entry 从空开始，避免“继续上次配置”抢镜）；
- 飞行模式 / 关 Wi-Fi，证明离线；
- 屏幕镜像已连，字体/亮度固定；
- 备一份录屏，真机失败直接播；
- 记住三个数字：**7800 → 7900**，BIOS 始终“未验证”。

## 2. 9 步真机

### Step 1 · Entry（30s）

- 预算 `8000`，用途 `游戏`；
- 说：“先看预算推荐，再看固定锚点配置。”
- 点 **生成配置** → 6 类、总价约 `7869`，权重卡可见；
- 点 **返回**，再点 **载入演示配置 · ¥7,800**（答辩锚点）。

### Step 2 · Workspace（30s）

- 总价 `¥7,800`，剩余 `¥200`；
- 指出 337mm 显卡与 320mm 机箱同屏。

### Step 3 · 保存 A（15s）

- 点 **保存当前配置**，记为 A；
- 说：“A 是修改前的基线，稍后和 B 比较。”

### Step 4 · 检查（60s）

- 点 **检查兼容性**；
- 顶部 `存在冲突`，分数 52；
- 第一条 `显卡长度 BLOCKER`：337 vs 320；
- 往下指 BIOS：`未验证——缺少 biosGeneration`；
- 说：“BLOCKER 是装不上；未验证不是通过。”

### Step 5 · 候选（45s）

- 点第一条冲突的 **看看能换成什么**；
- 候选 rank 1：300mm，`+¥100`；
- 说：“先过滤会引入新 BLOCKER 的候选，再按价格/影响排序。”

### Step 6 · 预览（30s）

- 点 **预览**；
- 新总价 `¥7,900`，仍在 8000 内；
- 强调：预览不改当前 revision。

### Step 7 · 应用 + 重检（45s）

- 点 **应用并全量重检**；
- 显示 `已应用并重检`，总价 7900；
- 返回配置页；BIOS 仍 `未验证`；
- 说：“修一个冲突 ≠ 全部兼容。”

### Step 8 · 保存 B + 比较（60s）

- 点 **保存当前配置**，记为 B（7900）；
- 点 **比较已保存的 2 份配置**；
- 两列：A 7800 / B 7900，差异高亮；
- 说：“比较只展示可判定字段，不预测帧数。”

### Step 9 · 收口（30s）

- 回 Entry，点 **继续上次配置 · 已保存 2 份**，证明 Room 持久化；
- 一句话：“证据最弱决定结论；改配置必须重新检查。”

## 3. Q&A 速答

| 问题 | 回答 |
|---|---|
| 价格是实时的吗？ | 不是。静态目录 + 带日期的参考价，离线可用；不承诺库存。 |
| 为什么是 15 条规则？ | 首版只做可判定、可解释的硬约束；每条有 4 态 fixture。 |
| 三态证据是什么？ | VERIFIED / REPORTED / EMPTY；最弱传播，缺字段只能未验证。 |
| 为什么 BIOS 不通过？ | 目录缺 `biosGeneration`，无法判定；不猜。 |
| 替换怎么选？ | 先过滤目标冲突未消除/引入新 BLOCKER 的候选，再按价格差、影响规则数、ID 排序。 |
| 推荐是最优吗？ | 不是；启发式 + 可见权重，只保证预算内、无 BLOCKER。 |
| 没有独显呢？ | 无 GPU 时 CPU 必须有核显，否则 Guard 拒绝。 |
| 杀进程数据还在吗？ | 保存的 A/B 在 Room；诊断需重新检查（绑定 revision）。 |
| CPU/主板能改数量吗？ | 不能。单件类目固定 1 件，改多件会价格翻倍但兼容结论不变，所以直接拒绝（ADR-0010）；只有内存/硬盘能改数量。 |
| 怎么证明测试不是摆设？ | 60 fixture、76 格状态机、18 不变量、12 变异、Room 契约；矩阵从真实 JUnit 生成。 |
| 数据哪来的？ | 官方商城/公开报价页，日期与来源在 `assets/catalogue/SOURCES.md`；不爬实时价。 |
| 为什么不做 3D/FPS？ | 范围外；先把兼容性与证据闭环做对。 |
| 下一步？ | 签名 Release、答辩材料、更多官方商城 adapter；不扩实时价。 |

## 4. 不能说

- “保证整机一定兼容”
- “价格实时/最低”
- “最优配置”
- “AI/机器学习推荐”
- “准确率 / 用户数 / 完成百分比”
- “FPS / 跑分 / 性能 band”

## 5. 现场兜底

| 故障 | 处理 |
|---|---|
| 候选列表为空 | 回 Workspace 重检；仍空则切录屏，口述候选排序 |
| App 崩溃 | 重开；Entry 有已保存配置；仍不行播录屏 |
| 数字不一致 | 以屏幕为准，不背稿；说“以当前快照为准” |
| 时间不够 | 砍 Step 1 的 D4，直接 7800 锚点；保留 BIOS/比较 |
